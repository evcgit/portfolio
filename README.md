# Evan Cortez Portfolio

Premium personal portfolio for Evan Cortez — software engineer and product builder.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
- `node scripts/capture-screenshots.mjs` — refresh BidzBase screenshots

## Notes

- Command palette: `/` or `Cmd/Ctrl + K`
- Resume file: `public/resume.pdf`
- BidzBase demo: https://bidzbase.com/login?demo=1
